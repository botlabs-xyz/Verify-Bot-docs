## Privacy Policy

VerifyBot processes only the server/user data needed to run verification and trust workflows.

### Data categories

- Discord identifiers (server, channel, role, user IDs)
- Verification event metadata
- Command usage metadata
- Logging metadata when configured

### Why data is used

- Execute verification commands and role workflows
- Generate audit logs for moderation visibility
- Diagnose failures and improve reliability

### Retention

Operational data and logs are retained only as needed for verification operations, moderation context, and support.

### Sharing

Data is not sold. Data may be processed through infrastructure providers required to operate the service.
